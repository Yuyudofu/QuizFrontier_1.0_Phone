# GAS同期の導入

## 1. スプレッドシートを作る

1. Googleスプレッドシートを新規作成する
2. 拡張機能 → Apps Scriptを開く
3. `Code.gs`の内容を貼り付ける
4. プロジェクト設定 → スクリプトプロパティで次を追加する

```text
プロパティ名: SYNC_TOKEN
値: 自分で作った長いランダム文字列
```

5. デプロイ → 新しいデプロイ → ウェブアプリ
6. 次の設定にする
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
7. 表示された`/exec` URLをコピーする

## 2. アプリへ入力する

アプリの「同期」を開き、次を入力します。

- GAS WebアプリURL
- `SYNC_TOKEN`に設定した同じトークン
- 同期する問題セット

「設定を保存」で保存し、「読み込み・同期」で初回同期します。

## 3. 同期の動作

- 読み込みは「クラウドから読み取り」を押したときだけ行う
- 書き込みは「クラウドへ書き込み」を押したときだけ行う
- 一度読み込んだ内容を端末側で使い、画面表示のたびにはGASへアクセスしない
- 問題を保存しただけではGASへ自動的に書き込まない
- 詳細な解答履歴はGASへ送らない
- 同期対象外のデッキは端末に残り、GASへは送らない
- 同期対象外に変更したデッキのクラウドデータは削除せず、次回以降もスプレッドシートに保持する

30,000問を想定し、スプレッドシートは1問1行で保存します。問題文と答えが長い場合は、GASの6分実行時間やスプレッドシート容量に近づくため、デッキを分けて同期してください。
